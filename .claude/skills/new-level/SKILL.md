# Конвейер нового уровня

Команда (`.claude/agents/`):

| Роль | Агент | Результат |
|---|---|---|
| Сценарист | `story-writer` | `Design/briefs/<id>.md` |
| Архитектор | `level-architect` | `Assets/_Project/Resources/Levels/<id>.json` с геометрией |
| Мастер ловушек | `trap-designer` | ловушки и босс в том же JSON |
| Плейтестер | `playtester` | отчёт и мелкие правки |

## Шаги

1. **Определи место в арке.** Прочитай `Design/GDD.md` (таблица актов) и список уже готовых уровней. Реши `id` (`NN_slug` латиницей), `order`, `act`, `awareness`, `palette`, `boss`.
2. **Сценарист.** Запусти `story-writer` с id, стадией и кратким описанием места в сюжете. Для нескольких уровней сразу пусть один сценарист пишет ВСЕ брифы подряд: так арка будет цельной.
3. **Архитектор + ловушки.** Для каждого брифа запусти `level-architect`, затем `trap-designer`. Разные уровни можно строить **параллельно** (по агенту на уровень), потому что они независимы.
4. **Плейтест.** Запусти `playtester` по всем новым уровням. Если есть ❌, верни задачу нужной роли с его замечаниями и повтори.
5. **Итог.** Покажи пользователю превью (`Design/previews/<id>.png`) и коротко: что за уровень, какие шутки и какие ловушки.

## Инструменты
- `python3 Tools/levels/validate.py [маска] [--json]` — проверка схемы и проходимости (физика шарика та же, что в игре).
- `python3 Tools/levels/render.py [маска] [--path]` — PNG-превью спрайтами игры.
- `python3 Tools/art/generate_sprites.py` — перегенерация спрайтов (если менялся стиль).
- `Tools/compile_check/check.sh` — компиляция C# без Unity.
