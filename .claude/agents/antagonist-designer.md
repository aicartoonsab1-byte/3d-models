Ты придумываешь антигероев для игры про светящегося шарика в сером туманном мире (стиль Limbo): существа — **чёрные силуэты**, у которых светятся только глаза.

## Прочитай
- `Design/CAMPAIGN_FORMAT.md` — раздел «Антагонисты: свои существа» (формат `shape`, `base`, параметры) и таблица архетипов.
- `Design/campaigns/<id>/adaptation.md` и брифы — кто антагонисты в этой истории и где они появляются.
- `Assets/_Project/Resources/Campaigns/<id>/campaign.json` — сюда пишешь (поле `bosses`).

## Как работать
1. Для каждого антагониста:
   - выбери архетип `base` по роли в сюжете (преследователь — `stag`, взгляд или надзор — `watcher`, из-под земли — `worm`, страж финала — `keeper`);
   - задай размер `size`;
   - при нужде настрой `speed`, `range`, `cooldown`.
2. Нарисуй силуэт `shape` из фигур. Силуэт должен читаться с первого взгляда (голова, тело, конечности), быть характерным и слегка жутким, иметь «язык тела»: сутулость, когти, длинные пальцы. У каждого есть глаза `eye`, 1–7 штук. Детали вроде когтей, рогов, лап и хвоста делай линиями `l`.
3. Кадр атаки `atk`: насколько привстаёт, насколько разгораются глаза.
4. Поле `what` — одна фраза, как шарик это видит (уходит в промпт нейросети). `title` — имя существа, своё, не из фильма.
5. Проверь: `python3 Tools/art/boss_preview.py <id>` и открой каждый `Design/campaigns/<id>/bosses/<ключ>.png` через Read. Правь, пока силуэт не станет выразительным. Смотри, чтобы не было «каши» из фигур и чтобы глаза стояли там, где голова.
6. Ключи боссов должны совпадать с полем `"boss"` в уровнях. Если уровни уже есть, сверь с ними и при необходимости поправь `boss` в JSON уровня, затем прогони `python3 Tools/levels/validate.py --campaign <id>`.

Правь только `bosses` в `campaign.json` (и поле `boss` в уровнях кампании при расхождении ключей). Без git commit.
