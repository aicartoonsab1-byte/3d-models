# SAM_Toons — план

Цель: вы даёте тему и короткий сюжет, агенты делают 5-минутный горизонтальный рисованный мультфильм
в стиле «тонкая чёрная линия на белом». Всё на вашем ПК (RTX 3070 8 ГБ, 32 ГБ ОЗУ), только бесплатные локальные модели.

## Главный принцип

**Мультфильм — это данные, а не картинки.** Агенты пишут `film.json` (сцены → биты → реплики и действия),
а рисует всегда один и тот же детерминированный движок. Поэтому:
- персонаж выглядит одинаково во всех сценах;
- правка — это изменение поля в JSON, а не перерисовка кадра;
- валидатор ловит ошибки агента, и агент их сам исправляет;
- 7–9B-модели, которые помещаются в 8 ГБ, справляются: они пишут структуру, а не рисуют.

## Конвейер

```
тема + сюжет (вы)
  1. Сценарист     → script.md: логлайн, персонажи, 8–12 сцен, реплики        ⏸ вы читаете и правите
  2. Режиссёр      → film.json по сцене за раз (JSON-схема) → check → исправление → озвучка → раскадровка
  3. Критик        → смотрит storyboard.png (vision-модель) + film.json → оценки по чек-листу + правки JSON
                     (2–3 круга, после каждого check и новая раскадровка)                ⏸ вы утверждаете
  4. Аниматор      → «оживление»: реакции фоновых персонажей, значки, акценты камеры, звуки, паузы
  5. Монтажёр      → финальная озвучка, музыка с приглушением под речью, рендер MP4 + .srt + обложка
```

Каждый шаг читает и пишет файлы в `films/<фильм>/`, поэтому любой шаг можно перезапустить, откатить или поправить руками.

## Модели под RTX 3070 (8 ГБ)

Выбор хранится в конфиге и меняется одной строкой. Ориентиры на момент написания:

| роль | модель (Ollama) | заметка |
|---|---|---|
| сценарист, режиссёр, аниматор | Qwen3 8B (Q4) | хорошо пишет по-русски, держит JSON-схему; 14B влезает с выгрузкой части слоёв в ОЗУ — медленнее, но лучше тексты |
| критик (видит кадры) | Qwen2.5-VL 7B / Qwen3-VL 8B или Gemma 3 (vision) | смотрит лист раскадровки |
| голоса | **Fun-CosyVoice3-0.5B** (подключена: клон по образцу, эмоции, Apache-2.0), запасные — Piper, RHVoice, eSpeak | ставится в отдельное окружение, см. COSYVOICE.md |
| музыка | свои или бесплатные треки; опционально MusicGen-small | MusicGen — некоммерческая лицензия |

Одновременно в видеопамяти помещается одна модель, Ollama переключает их сама; шаги идут последовательно.

## «Виральность» — честно

Модель не умеет предсказывать просмотры. Критик проверяет конкретный список:
крючок в первые 5 секунд, ясный конфликт к 30-й секунде, статичных кадров не дольше 6 с, смена плана каждые 3–8 с,
панчлайн в конце каждой сцены, повторяющийся гэг, персонажей узнать по силуэту, субтитры короткие,
финал, который хочется пересмотреть.

## Этапы

1. **Вертикальный срез** ✅ — движок (перо «от руки», человечки на скелете, 22 позы, 11 настроений, эмоции,
   НЛО, казино, деревья, облака, камера, тряска), озвучка (Piper/RHVoice/eSpeak), губы по громкости,
   процедурные звуки, раскадровка, рендер MP4. Демо: `films/ufo_casino`.
2. **Библиотека** — улица, комната, мебель, машина, магазин, ночь; предметы в руках; профиль при ходьбе;
   Silero TTS; музыка; субтитры .srt; переходы между сценами.
3. **Сценарист и режиссёр** ✅ (`studio/agents.py`) — Ollama, JSON-схемы, цикл «сгенерировал → episode_check → исправил», сцена за сценой.
   `sam.py write <серия> --idea "…"` → script.md; `sam.py direct <серия>` → episode.json (планы Blender, docs/EPISODE_FORMAT.md).
4. **Критик** ✅ — vision-модель смотрит лист ключевых кадров (`episode --stills`), ставит оценки по чек-листу
   и присылает патчи к episode.json; патчи, которые ломают проверку, не применяются. `sam.py critique <серия>`, отчёт — build/critique.json.
   Проверено на заглушке модели; на ПК с Ollama качество зависит от модели (см. таблицу выше).
5. **Студия** — локальное веб-приложение: редактор сценария, сетка раскадровки с комментариями к кадрам,
   кнопки «утвердить» и «переделать», история версий.
6. **Пилот** — серия «Болотная планета. Всё будет богомол» (`films/swamp_ep1`): сценарий → episode.json → Blender-рендер
   серии целиком со звуком и субтитрами (`sam.py episode swamp_ep1`). Дальше — доводка и 5-минутный формат.
