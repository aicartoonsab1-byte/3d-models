# Живые голоса через Applio (RVC)

[Applio](https://github.com/IAHispano/Applio) — бесплатная локальная программа для **замены голоса** (RVC).
В студии она работает как последний шаг озвучки:

```
текст → Piper / CosyVoice (кто что говорит, с интонацией) → «оживление» → Applio (чьим голосом) → реплика
```

TTS отвечает за слова и интонацию, а RVC-модель перекрашивает их в голос персонажа: живой тембр, дыхание, характер.
RVC-голоса бывают любые: готовые модели (их тысячи) или своя, обученная на 10–30 минутах записи.

## Установка (Windows, один раз)

1. Скачайте Applio: на странице https://github.com/IAHispano/Applio/releases возьмите последний релиз
   (архив `ApplioV….zip`) и распакуйте, например, в `C:\Applio`.
   Или через git: `git clone https://github.com/IAHispano/Applio.git C:\Applio`.
2. Запустите `C:\Applio\run-install.bat`. Он сам поставит Miniconda и Python 3.12 в `C:\Applio\env`,
   а также PyTorch с CUDA (для RTX 3070). Это займёт 10–20 минут.
3. Запустите `C:\Applio\run-applio.bat` один раз. Откроется окно в браузере, и Applio докачает нужные модели
   (rmvpe, contentvec). После этого окно можно закрыть: студия вызывает Applio сама, без интерфейса.
4. Сообщите студии, где лежит Applio: создайте файл `SAM_Toons\studio\engines.local.json`
   (если он уже есть из-за CosyVoice, добавьте раздел `applio`):
   ```json
   { "applio": { "dir": "C:/Applio" } }
   ```

## Голоса персонажей

1. Положите RVC-модель в `SAM_Toons\models\rvc\`: файл `<имя>.pth` и, если есть, `<имя>.index`.
   Готовые модели скачиваются как zip с `.pth` и `.index`; взять их можно, например, во вкладке Download в самом Applio.
2. В `film.json` у персонажа укажите:
   ```json
   "boris": { "type": "human", "voice": "man_young", "rvc": { "model": "boris", "pitch": 0 } }
   ```
   - `model` — имя файла без `.pth`;
   - `pitch` — сдвиг в полутонах (мужская модель для женского TTS: примерно −12, и наоборот +12);
   - по желанию `index_rate` (0…1, по умолчанию 0.5: чем больше, тем ближе к тембру модели) и `protect` (0.33 — бережёт согласные).
3. `python studio\sam.py voice <фильм>`: реплики этого персонажа пройдут через Applio (одним запуском на модель).

Если Applio или модель не найдены, студия предупредит и озвучит без замены голоса. Проверка связки без Applio:
`{ "applio": { "dir": "C:/Applio", "mock": true } }` — реплики просто копируются.

## Своя модель голоса (самое живое)

В интерфейсе Applio есть вкладка **Train**. Нужно 10–30 минут чистой записи одного человека, который говорит
в нужной манере: быстро, смешно, с эмоцией. На RTX 3070 обучение занимает около часа.
Записывайте свои голоса или голоса друзей с их согласия: чужой голос (например, из чужого ролика) без разрешения
использовать нельзя.

Лучшее сочетание для «живых смешных» голосов: **CosyVoice** (интонация и манера по образцу) + **Applio** (тембр).
