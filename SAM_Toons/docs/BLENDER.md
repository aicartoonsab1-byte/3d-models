# Анимация в Blender: живые движения, рисованный вид

Почему Blender: 2D-движок двигает «бумажных кукол» формулами, и это всегда выглядит механически.
В Blender персонажи — мягкие тела на скелете, а движения берутся из **записей реальных людей** (мокап).
Картинка при этом остаётся «рисованной»: плоские мультяшные заливки, контур от руки (Freestyle), зерно и виньетка.

## Установка (Windows)

1. Blender 4.x с https://www.blender.org/download/ (бесплатно). Добавьте папку Blender в PATH
   (или запускайте `blender.exe` по полному пути). Рендер Eevee использует вашу RTX 3070, это быстро.
2. Движения: `python blender\get_mocap.py` скачает подборку записей базы CMU в `models\mocap\`
   (бесплатно, любое использование, ~15 МБ). Вся база — 2548 записей, оглавление: `python blender\get_mocap.py --index`.
3. Каталог кадров, чтобы выбирать куски движений:
   `blender -b --factory-startup -P blender\tools\catalog.py` → `models\mocap\catalog\*.jpg`.

## Стили рисовки (`"style"` в shot.json)

- `"look": "mult"` — как в референсе-мульте: всё белое, форма только тонким чёрным контуром «от руки», крапинки
  бумаги на земле, кудрявые деревья и кусты (`set.bushes`). Никаких цветов: чёрные заливки — только глаза-точки и рот.
  Половина морды-богомола отделяется от капибарьей линией-швом. (Красный акцент можно вернуть: `look.MULT_ACCENT = True`.)
  Персонажи — «фасолины»: скелет мокапа укорачивается (короткие ножки, большая голова), движения остаются живыми.
  Параметры: `line` (толщина контура, 1.75), `wobble` (дрожание линии), `speckles` (сколько крапинок).
- `"look": "dusk"` — сумеречные мультяшные заливки (бирюзовое небо, охристое пальто), зерно и виньетка.
- `"twos": true` — рисунок меняется через кадр (12,5 раз в секунду), как в рисованной анимации; рендер вдвое быстрее.

Пример: `films/swamp_mult/shot.json` (mult) и `films/swamp_3d/shot.json` (dusk).

## Сцена: `films/<сцена>/shot.json`

```json
{
  "fps": 25, "size": [1920, 1080], "duration": 12.5,
  "cast": { "boris": { "voice": "man_young" } },
  "set": { "trees": [[x, y, высота]], "reeds": [[x, y]], "pools": [[x, y, ширина, глубина]], "glow": [[x, y]] },
  "boris": { "start": [x, y], "hold": "camera", "segments": [
      { "clip": "82_08", "from": 8.2, "to": 10.8, "at": 0.0, "face": 90 },
      { "clip": "77_01", "from": 5.7, "to": 7.4, "face": 0, "blend": 0.45 } ] },
  "capy": { "hops": { "from": -8, "to": 2.4, "y": 2.6, "t0": 3.6, "t1": 6.4, "turn_at": 6.7 } },
  "camera": [ { "t": 0, "pos": [x, y, z], "look": [x, y, z] } ],
  "lines": [ { "who": "boris", "t": 6.1, "text": "О! Видели?!", "mood": "surprised" } ],
  "sfx": [ { "t": 3.6, "name": "boing" } ]
}
```

- Оси: X — вправо по экрану, Y — вглубь (от камеры), Z — вверх; метры. Камера по умолчанию смотрит вдоль +Y.
- **Сегмент движения**: кусок записи `clip` от `from` до `to` (секунды). Следующий кусок начинается там, где
  остановился предыдущий, позы плавно перетекают за `blend` секунд. `face` — куда смотрит персонаж:
  0 — в камеру, 90 — вправо, −90 — влево, 180 — от камеры. `speed` ускоряет или замедляет кусок, `hold` держит последнюю позу.
- Камера двигается плавно между ключами (разгон и торможение), смотрит на точку `look`.
- Реплики озвучиваются голосовой студией (Piper/CosyVoice/Applio), рот двигается по громкости, глаза моргают сами.

## Запуск

```bat
python studio\sam.py shot swamp_3d --frames 1-1     :: один кадр — проверить композицию
python studio\sam.py shot swamp_3d                  :: вся сцена → films\swamp_3d\build\shot.mp4
```

## Как устроено (`blender/sam3d/`)

- `mocap.py` — загрузка BVH, склейка сегментов: приклеенный корень, поворот по `face`, плавные переходы (кватернионы).
- `character.py` — «фасолина» (`build_bean`, стиль mult: укороченный скелет, голова-шар, глаза-точки, хохолок,
  красный шарф) и человек (`build_human`, стиль dusk): оболочка по костям (Skin → сглаживание) с автоматическими весами, пальто со своими весами,
  крупная голова, глаза, брови, рот (липсинк), моргание, рюкзак, камера в руке.
- `creature.py` — капибара-кенгуру: свой скелет, прыжки по принципам анимации (присед → толчок → дуга → сжатие при
  приземлении, запаздывающий хвост), поворот морды — видна половина-богомол.
- `world.py` — болото: земля, лужи, камыши, светящиеся растения, деревья со мхом и плодами, холмы, луны, свет, камера.
- `look.py` — мультяшные материалы (ровные заливки света и тени), небо-градиент, контур Freestyle «от руки».
