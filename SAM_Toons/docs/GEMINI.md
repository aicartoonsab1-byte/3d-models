# Gemini: видео Veo и озвучка

Необязательный облачный модуль (всё остальное в студии работает локально). Нужен ключ Gemini API.

## Ключ
1. Google AI Studio → **Get API key** → создать ключ. Veo доступен только на платном тарифе. Цены и лимиты смотрите в AI Studio: они меняются.
2. Положить ключ **в переменную окружения**, не в файлы проекта:
   ```bat
   setx GEMINI_API_KEY "ваш_ключ"
   ```
   (закрыть и заново открыть окно командной строки). Ключ никогда не пишется в git и не показывается в чате/скриншотах.
3. Имена моделей — в `studio/gemini.json` (Google часто их меняет; свои правки — в `studio/gemini.local.json`, он не в git).

## Озвучка (Gemini TTS)
Движок `gemini` стоит первым во всех пресетах `studio/voices.json`; без ключа озвучивает Piper, как раньше.
- Голос пресета и его манера — `studio/gemini.json` → `voices` (например, рассказчик `Charon` «сухо, с иронией», Борис `Puck`).
- Характер персонажа — `cast.<id>.style` в episode.json («самоуверенный блогер, храбрится»), свой голос — `cast.<id>.gemini_voice`.
- Как сказать конкретную реплику — `mood` и ремарка `how` у реплики: `{"who": "boris", "text": "…", "how": "шёпотом, запыхавшись"}`.
Интонацию Gemini играет сам, поэтому Praat-«оживление» и сдвиг высоты к нему не применяются.

## Видео (Veo) — шоураннер и оценщик
```bash
python studio/sam.py episode swamp_ep1 --stills   # раскадровка: кадры-якоря из Blender (бесплатно)
python studio/sam.py veo swamp_ep1 --plan         # шоураннер выбирает планы и пишет промпты → build/veo/plan.json (видео не тратится)
python studio/sam.py veo swamp_ep1                # съёмка по плану (или --shots s5a,s6a; --fast — быстрая модель)
python studio/sam.py episode swamp_ep1 --veo      # монтаж: принятые ролики Veo вместо планов Blender → episode_final_veo.mp4
```
Генераций мало, поэтому:
- **Шоураннер** (Gemini) отдаёт Veo только планы, где он даёт больше всего: существа, действие, превращения.
  Говорящие головы остаются из Blender. `plan.json` можно поправить руками (`use_veo`, промпты) до съёмки.
- **Кадр-якорь.** Каждый ролик начинается с кадра раскадровки Blender, поэтому персонажи и место совпадают с остальными планами.
  Длинный план снимается кусками по 4–8 с, и каждый следующий кусок начинается с последнего кадра предыдущего.
- **Проверка промпта** до генерации: Gemini сверяет промпт с кадром-якорем. Это текстовый запрос, видео он не тратит.
- **Оценщик** смотрит каждый дубль и ставит баллы: стиль, персонаж, действие, артефакты. Ниже `accept_score` (7) — пишет
  исправленный промпт, и дубль переснимается (до `max_takes`). Если хорошего дубля нет, план остаётся из Blender.
- **Бюджет.** `daily_video_seconds` в `gemini.json`; расход пишется в `build/gemini_usage.json`. Когда лимит кончился,
  работа останавливается и продолжается той же командой на следующий день (`build/veo/state.json`).
- **Звук всегда наш**: реплики (Gemini TTS), звуки и фон. Звук из Veo не используется, потому что его реплики не совпали бы с озвучкой.
  Поэтому в промптах персонажи «не говорят в кадр».
- Стиль и описания персонажей для промптов — `episode.json` → `veo` (`style`, `characters`, `negative`).
