# Кампании «по мотивам фильма»

Кампания — это отдельная игра на том же движке. В ней свой герой-шарик с характером главного героя фильма, свои уровни по ключевым сценам и свои антагонисты-боссы.

Основная игра «Шарик» — кампания `sharik`. Её файлы лежат по старым путям: `Resources/Levels`, `Resources/Brain`.

## Где лежит

```
Assets/_Project/Resources/Campaigns/<id>/
  campaign.json          # герой, антагонисты, финал, фразы
  levels/NN_slug.json    # уровни (формат — Design/LEVEL_FORMAT.md)
Design/campaigns/<id>/   # сценарий-адаптация, брифы уровней, скрипты сборки, превью
```

## campaign.json

| Поле | Что это |
|---|---|
| `id` | латиница, как имя папки |
| `title` | название игры: «Тень над Висбургом» |
| `source` | «по мотивам …» — честно указываем первоисточник |
| `logline` | 1–2 предложения для стартового экрана |
| `hero.name` | имя героя-шарика (своё, не имя персонажа фильма) |
| `hero.persona` | характер для нейросети: тот же формат, что `Resources/Brain/persona_ru.txt` — ХАРАКТЕР, СТАДИИ (0–5 — арка героя), ВАЖНО. Без блока «ДЕЙСТВИЯ»: схему ответа движок добавит сам |
| `hero.traits` | стартовые черты: `curiosity`, `courage`, `trust`, `humor` (0..1) |
| `bosses.<ключ>` | антагонисты кампании (см. ниже). Уровень ссылается на ключ полем `"boss"` и клеткой `B` |
| `finale` | `{ "switch": "что такое R в этой истории", "end": "КОНЕЦ-заголовок", "text": "финальные строки (\\n — перенос)" }` |
| `phrases` | офлайн-фразы, формат `phrases_ru.json` (`[{key, stage, mood, lines}]`); чего нет — берётся из основной игры |

## Антагонисты: свои существа

```json
"bosses": {
  "count": {
    "title": "Граф Ночи",
    "what": "высокий сутулый силуэт с когтями, глаза горят в темноте (так шарик его видит — для нейросети)",
    "base": "keeper",
    "size": [3, 4],
    "speed": 1.6, "range": 8, "cooldown": 4.5,
    "shape": [
      {"e": [50, 30, 18, 22]},
      {"p": [30, 45, 70, 45, 80, 100, 20, 100]},
      {"l": [30, 55, 10, 80, 5, 70], "w": 3},
      {"eye": [44, 28, 3]}, {"eye": [56, 28, 3]}
    ],
    "atk": {"dy": -6, "eyes": 1.8}
  }
}
```

- `base` — поведение-архетип (таблица ниже). Если ключ сам равен `stag`, `watcher`, `worm` или `keeper`, `base` можно не писать.
- `size` — габариты в клетках `[ширина, высота]`.
- `speed`, `range`, `cooldown` — скорость ходьбы или полёта, дальность атаки и перезарядка (необязательные поля).
- `shape` — силуэт в коробке 0..100 × 0..100, которая растягивается на `size`. Всё рисуется **чёрным силуэтом** (стиль Limbo), кроме глаз:
  - `{"e": [cx, cy, rx, ry]}` — эллипс;
  - `{"c": [cx, cy, r]}` — круг;
  - `{"p": [x1, y1, x2, y2, …]}` — многоугольник;
  - `{"l": [x1, y1, x2, y2, …], "w": 2}` — линия или ломаная толщиной `w` (лапы, рога, когти, щупальца);
  - `{"eye": [x, y, r]}` — **светящийся глаз**.
- `atk` — кадр атаки: `dy` (подпрыгнуть или привстать, в единицах коробки) и `eyes` (во сколько раз глаза разгораются). Кадр «моргает» — без глаз, его движок делает сам.
- Без `shape` используется стандартный силуэт архетипа.
- Проверка вида: `python3 Tools/art/boss_preview.py <id>` рисует `Design/campaigns/<id>/bosses/<ключ>.png` (покой / атака / моргает).

## Архетипы поведения

| `base` | Что делает | Подходит для |
|---|---|---|
| `stag` | ходит за шариком, топот подбрасывает | большой зверь, погоня, преследователь |
| `watcher` | парит над дорогой, стреляет взглядом | злой взгляд, надзиратель, гипнотизёр, камера |
| `worm` | выныривает из-под земли под шариком | крысы, чудовище из глубины, подполье |
| `keeper` | лежит у финальной цели, отбрасывает рёвом | главный злодей в логове, страж финала |

Ловушки и механики уровней (`^ C T W J X O > < ~ @`, `dark`) переосмысляются текстом реплик. Например, шипы становятся «кольями ограды», а пресс — «крышкой гроба».

## Права

Переносим **арку, архетипы, атмосферу и ключевые ситуации**, но не тексты. Имена персонажей, реплики и узнаваемые визуальные образы чужого фильма не копируем. Всё пишется заново. Фильмы в общественном достоянии (например, «Носферату» 1922, «Метрополис» 1927, «Путешествие на Луну» 1902) можно адаптировать свободнее, но и там пишем своё.
